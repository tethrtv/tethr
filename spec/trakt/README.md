# Trakt API snapshot

The parts of Trakt's OpenAPI document that Tethr serves, taken from https://developer.trakt.tv/openapi.json on 1 November 2026. Trakt generates it from the MIT-licensed contract in https://github.com/trakt/trakt-api, and its licence is in `LICENSE`.

The tests in `internal/traktcompat` check Tethr's answers against it.
